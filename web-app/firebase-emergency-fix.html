ขีดจำกัดฟรี:

  • 📖 อ่านข้อมูล: 50,000 operations/วัน
  • ✍️ เขียนข้อมูล: 20,000 operations/วัน
  • 💾 พื้นที่เก็บข้อมูล: 1 GB
  • 🌐 Bandwidth: 10 GB/เดือน

ผลกระทบ: ไม่สามารถใช้งานระบบได้จนกว่า quota จะ reset (24 ชั่วโมง) หรือ upgrade plan

🔧 วิธีแก้ไขด่วน (ใช้ได้ทันที)

ตัวเลือก 1: รอให้ quota reset ในวันถัดไป (ฟรี)

ตัวเลือก 2: upgrade เป็น Firebase Blaze Plan (เสียค่าใช้จ่าย)

ตัวเลือก 3: ใช้งานแบบ offline ด้วย cached data

🎯 ขั้นตอนที่ 1: เพิ่ม Caching ให้ระบบ

ลดการเรียกใช้ Firebase โดยใช้ cache ในเบราว์เซอร์

1.1 แก้ไขไฟล์ firebase-real-config.js

// เพิ่มบรรทัดนี้ที่ด้านบน import { enablePersistence } from 'https://www.gstatic.com/firebasejs/9.23.0/firebase-firestore.js'; // เพิ่มหลังจาก db = getFirestore(app); enablePersistence(db).then(() => { console.log('✅ Firestore offline persistence enabled'); }).catch((err) => { console.warn('⚠️ Offline persistence failed:', err); });

🎯 ขั้นตอนที่ 2: ปรับปรุงการโหลดข้อมูล

ใช้ pagination และลด real-time listeners

2.1 เพิ่ม Pagination ในการโหลดข้อมูล

// แทนที่การโหลดข้อมูลทั้งหมด // จาก: getDocs(collection(db, 'employees')) // เป็น: const q = query(collection(db, 'employees'), limit(50)); const snapshot = await getDocs(q); console.log('โหลดข้อมูล 50 รายการแรก');

2.2 ลด Real-time Listeners

// แทนที่ onSnapshot ด้วย getDocs ในส่วนที่ไม่ต้อง real-time // จาก: onSnapshot(q, (snapshot) => { ... }); // เป็น: getDocs(q).then((snapshot) => { ... });

🎯 ขั้นตอนที่ 3: ใช้ Local Storage Cache

เก็บข้อมูลที่ใช้บ่อยใน localStorage

// สร้างระบบ cache class FirebaseCache { static set(key, data, expireMinutes = 60) { const item = { data: data, timestamp: Date.now(), expire: expireMinutes * 60 * 1000 }; localStorage.setItem('fb_' + key, JSON.stringify(item)); } static get(key) { const item = localStorage.getItem('fb_' + key); if (!item) return null; const parsed = JSON.parse(item); if (Date.now() > parsed.timestamp + parsed.expire) { localStorage.removeItem('fb_' + key); return null; } return parsed.data; } } // ใช้งาน async function getEmployeesWithCache() { const cached = FirebaseCache.get('employees'); if (cached) { console.log('ใช้ข้อมูลจาก cache'); return cached; } const data = await getEmployees(); FirebaseCache.set('employees', data, 30); // cache 30 นาที return data; }
